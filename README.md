# Сайт «Спецтехника для ваших задач»

Одностраничный лендинг: демонтаж, земляные работы, вывоз мусора, благоустройство,
аренда спецтехники с оператором. Собран на базе шаблона `demontazh-site` в стиле
рекламного постера (тёмный фон + жёлтый акцент).

## Структура

```
index.html      — лендинг (стили и скрипты внутри файла)
privacy.html    — политика конфиденциальности
send.php        — обработчик формы заявки (email / Telegram)
favicon.svg     — иконка сайта
img/hero.jpg    — фото в шапке (эвакуатор + спецтехника)
img/work1.jpg   — демонтаж
img/work2.jpg   — подготовка участка
img/work3.jpg   — земляные работы
img/work4.jpg   — спецтехника в деле
```

Фото вырезаны из исходного рекламного постера
(https://cdn-edge.kwork.ru/files/uploaded/7d/b9/25/b53d3a4144/).

## Перед публикацией замените

1. **send.php → CONFIG**: `email_to`, `email_from`, `site_host` и/или
   `tg_token`, `tg_chat_id` (иначе заявки никуда не уходят).
2. **Яндекс.Метрика**: счётчик в `index.html` и `var YM_ID = 0;` → ваш номер счётчика.
3. **Домен**: `https://example.ru/` в `<link rel="canonical">` и `og:url`, а также
   `site_host` в `send.php`.
4. **privacy.html**: реквизиты оператора (ИП/ООО, ИНН, адрес) — сейчас плейсхолдеры.
5. При желании — реальный адрес/карта, Telegram, email: на постере этих данных нет,
   поэтому в контактах оставлен только телефон.
